# RyberID

**Modern Identity & Authentication Platform**

RyberID es una plataforma de identidad y autenticación multiplataforma
orientada a aplicaciones web, móviles y de escritorio.

El proyecto forma parte del ecosistema **RyberMain** y es creado y
mantenido por **Mark Will Ccallo Chambi**.

> Este proyecto se encuentra actualmente en su etapa inicial de diseño
> y desarrollo.

## Objetivo

Diseñar e implementar una plataforma moderna de identidad que permita
centralizar la autenticación y el control de acceso para diferentes
tipos de clientes y dispositivos.

## Alcance previsto

- Autenticación mediante Passkeys y WebAuthn.
- Autenticación entre dispositivos.
- Acceso mediante códigos QR.
- Gestión de dispositivos.
- Gestión de sesiones.
- Roles y permisos.
- Auditoría de eventos de autenticación.
- Recuperación segura de cuentas.
- Compatibilidad con aplicaciones web, móviles y de escritorio.

## Estado del proyecto

🚧 **En desarrollo**

Las funcionalidades indicadas forman parte del alcance previsto y no
deben considerarse implementadas hasta que sean incorporadas y
documentadas en una versión del proyecto.
