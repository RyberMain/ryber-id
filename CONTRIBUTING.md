# Contributing to RyberID

Gracias por tu interés en contribuir a RyberID.

El proyecto se encuentra actualmente en desarrollo inicial.

## Principios

Las contribuciones deben:

- mantener el enfoque de seguridad del proyecto;
- utilizar estándares abiertos y tecnologías ampliamente aceptadas;
- evitar criptografía personalizada;
- incluir pruebas cuando corresponda;
- mantener una estructura de código clara y documentada;
- no incluir credenciales, secretos ni datos reales de terceros.

## Flujo de trabajo

Los cambios deberán realizarse mediante ramas específicas y,
posteriormente, mediante Pull Requests.

Las convenciones completas de ramas, commits, revisión y pruebas serán
documentadas conforme se establezca el flujo de desarrollo del proyecto.

## Licencia de las contribuciones

Al contribuir a este proyecto, aceptas que tu contribución se distribuya
bajo los términos de la Apache License, Version 2.0.
