# Security Policy

La seguridad es un componente central de RyberID.

## Reporte de vulnerabilidades

No publiques vulnerabilidades, credenciales, secretos ni información
sensible mediante issues públicos.

Si identificas una posible vulnerabilidad, evita publicar:

- procedimientos completos de explotación;
- credenciales o tokens;
- claves privadas;
- información que permita comprometer una implementación;
- datos personales o confidenciales.

El mecanismo privado de reporte de vulnerabilidades será documentado
antes de la primera versión pública estable.

## Versiones soportadas

RyberID se encuentra actualmente en desarrollo inicial.

Las versiones soportadas se documentarán cuando exista la primera
versión publicada.

## Divulgación responsable

Se solicita dar tiempo razonable para investigar y corregir una
vulnerabilidad antes de realizar cualquier divulgación pública.
